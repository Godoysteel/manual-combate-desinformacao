# Manual de combate à desinformação

Respostas curtas, com fonte, para as mentiras políticas que mais circulam nas redes e no dia a dia. Escrito para quem tem uma mente progressista e quer defender suas ideias com fatos.

**Página online (Modo debate):** https://godoysteel.github.io/manual-combate-desinformacao/

## O que tem aqui

- **Modo debate** (`index.html`): página para usar no celular durante uma discussão. Busque por palavra (urna, vacina, imposto...), leia a resposta curta e copie com um toque.
- **Livreto para folhear** (`livreto/`): o manual completo, com virada de página.
- **PDFs** (`pdf/`):
  - A5, para mandar no WhatsApp;
  - A4, uma página por folha;
  - A4, para imprimir como livreto (frente e verso, virar pelo lado curto).

## Como usar no celular

1. Abra a página online e use "Adicionar à tela inicial" no menu do navegador.
2. Na hora do debate: pare, tire um print da afirmação, procure a palavra, reescreva a resposta com as suas palavras e responda uma vez.
3. Não cole texto idêntico em vários lugares: parece campanha organizada, exatamente o que o manual ensina a reconhecer.

## Nosso compromisso

- **Só afirmamos o que podemos provar.** Cada resposta indica onde conferir. Se errarmos, corrigimos.
- **O alvo é a mentira, não a pessoa.** Quem repassa costuma estar de boa-fé.
- **Fato ou opinião:** em temas de valores, o manual não chama a posição contrária de mentira. Pede o dado e mantém a conversa.

## Estatísticas

A página usa o [GoatCounter](https://www.goatcounter.com/), que conta acessos de forma anônima, sem cookies e sem dados pessoais. Registra apenas quais respostas foram copiadas ou abertas, as abas visitadas e os downloads.

## Comentários

Os comentários usam o [Giscus](https://giscus.app/), que guarda tudo nas Discussões deste repositório. Para comentar é preciso uma conta do GitHub. O Giscus só é carregado quando a pessoa toca em "Ver e escrever comentários". Ofensas, ataques, ameaças e dados pessoais de terceiros são apagados.

## Avisos

- Confira sempre a fonte original antes de citar. Os fatos e os canais de denúncia podem mudar com o tempo.
- As páginas sobre denúncia e sobre emprego orientam, mas **não substituem um advogado**.
- Este projeto não é vinculado a partido, candidato ou campanha.

## Enviar uma mentira

Viu uma mentira que não está no manual? Mande o texto da afirmação para quem te passou o link (grupo ou privado), **sem o nome, a foto ou o perfil de quem escreveu**. Ela só vira um caso depois de conferida, com fonte.

## Correções

Encontrou um erro, uma fonte quebrada ou um fato desatualizado? Abra uma *issue* neste repositório com o link da fonte correta.
